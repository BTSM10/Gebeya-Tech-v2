# Gebeya Week 1 Challenge — Slack Messages Analysis

Analysis of anonymized Slack messages from Gebeya Batch 6.

## Setup

```bash
pip install -r requirements.txt
```

## Project Structure

```
├── src/          # Source code (loader, utils, config)
├── tests/        # Unit tests
├── notebooks/    # Jupyter notebooks for EDA
├── docs/         # Documentation
└── .github/      # CI/CD workflows
```

## Data

The dataset is not tracked in this repo. Place the `anonymized/` folder in the project root.

## Run Tests

```bash
make test
```
